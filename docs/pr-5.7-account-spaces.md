# 5.7 切换账号与导入（PR 描述草稿）

首次登录空 Lux 账号时，先查询现有 `GET /api/me/playlists`，再决定是否展示导入弹窗；用户做出选择以前不连接同步 socket。默认/收藏歌曲数为零且无自建歌单才算空账号，查询失败不会按空账号处理。登录资料同步改为只拉取，移除空服务器资料自动回传的分支。用户明确导入后，复制本地空间的数据，再交给正常同步上传。

导入决定按服务器 ID + 用户 ID 持久化。全部导入包含歌单、播放记录、资料及独立复制的头像文件；选择导入只复制勾选歌单和可选播放记录。不复制同步游标、设备 ID 或全局设置。重复复制按 ID 去重，不删除本地原件。保留退出和删除退出都清除该账号 session/Keychain，回到本地空间；删除另外清理该空间根键、根指针引用的分片及头像目录。迁移备份、原始遗留数据、其他空间及共享缓存保持原样。导入决定独立保留，删除后再次登录也不重复弹窗。

同一服务器的多个账号分别保留 session 和 Keychain refresh token。保留兼容的服务器索引，另加账号索引；旧版服务器级 Keychain 项迁移给其已知账号所有者。空间列表按匹配的账号 session 判断状态；无 session 时只打开预填登录，不提前切换空间。

## 界面增加

- 15A：13E 居中纸色卡片/遮罩模式；登录成功背景、首次登录眉题、导入问题、说明和加粗真实计数；左侧「不导入」、描边「选择歌单…」、主按钮「全部导入」。硬件返回等同不导入。
- 15B：「选择歌单…」打开底部抽屉；账号眉题、标题、已选/总数、保留本地数据提示、全选、复选框、占位封面、歌单名/歌曲数、播放记录开关及说明、关闭、跳过、导入及计数徽标。初始选中非临时歌单，播放记录默认关闭；关闭回到 15A，跳过持久化不导入。
- 15C：账号/服务器眉题、退出问题、默认「保留在本机」和「从本机删除」两行及完整说明，复用 OptionRow 前置圆点；取消和主按钮退出登录。
- 15D：从 14A「切换账号」进入预览内的设置子页；返回、眉题、标题、说明、分区线/标题/真实数量、头像首字圆、名称、当前强调徽标、本地歌单数/存储体积、服务器/登录状态/使用状态、非当前行切换、添加账号、本机数据管理。
- 失败时在当前弹窗/列表内显示三语错误提示，并允许重试；提交期间禁用重复操作。
- 所有新增界面文案同时提供简体、繁体、英文。
