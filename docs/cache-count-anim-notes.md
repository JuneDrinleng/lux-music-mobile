移除本页初始化与缓存枚举的吞错为空分支；抛错时保留已有行，首次失败显示三语失败说明，可重新打开或重新扫描重试。原生桥内部若把缓存打开失败返回为空数组，JS 仍无法区分真实空缓存，属于既有边界，未修改原生缓存协议。增加卸载代次失效，避免旧读取回写。
