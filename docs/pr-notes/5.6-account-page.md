## Preview differences
- Authorized difference: compact shared buttons/back control use approximately 28px visible height with at least 44px touch targets; the shared compact underlined Save action retains its existing 14px text treatment.
- Initial-avatar backgrounds use the active theme's existing `accent.soft` token instead of the sample preview's fixed green tint. Real per-space avatar images replace sample initials when available; the 32px initial thumbnail contains an initial rather than the preview's empty sample circle.
- Device tiles and row chevrons use repository MDI icons instead of the HTML's placeholder glyphs.
- Session metadata omits the sample `上海`: the specified sessions API supplies no location. Actual profile/session/account-space values replace the preview fixtures.
- Eyebrow/metadata separators use the requested `•` rather than the HTML source's `·` (the PNG renders bullet separators).

- Native StatusBar replaces the mock clock/signal bar; preview index badges `14A/14C/14D` are presentation annotations and are not product UI.
- Content scrolls and respects actual status/gesture insets instead of being clipped into the static 390×844 HTML canvas. The account surface uses the existing auth-style modal pattern rather than the previous profile layer's horizontal animation; the static previews do not specify transitions.
