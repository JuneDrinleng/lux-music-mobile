# 转正前真机回归清单

用**即将转正的那个开发版预发布**的 APK 测，大约 20 分钟。两个通道共用同一个 applicationId，开发版可以覆盖安装到稳定版上并保留数据；Android 不能把较新的开发版降级回较旧的稳定版。

机型 / Android：　　包：standard | vivo　ABI：　　版本：0.x.0-dev.N

- [ ] 从当前稳定版（如 0.4.0）覆盖安装本开发版：歌单、设置、登录态、同步配置保留
- [ ] 冷启动无白屏/闪退；搜索并播放 2 个音源；连续快速切歌 10 次不崩溃
- [ ] 后台播放 / 通知栏 / 锁屏控制；歌单新建、加歌、排序
- [ ] 同步（本周期改过时）：LX 连接码 / Lux 账号登录 → 同步 → 冲突弹窗
- [ ] 更新通道：稳定 → 开发可以检测到开发版；开发 → 稳定显示「等下一个稳定版」，不弹出降级安装
- [ ] 旧版兼容：安装 0.3.1（或上一个稳定版），「检查更新」只看到稳定版，看不到开发版
- [ ] vivo 包能安装、启动、播放
- [ ] 转正发布后：同一周期的开发版检查更新能收到稳定版；稳定版用户能升级

hotfix 只测「修复点 + 冷启动 + 播放 + 从上一稳定版覆盖安装」。开发版预发布本身不强制手测。

转到 master 的 PR（转正或 hotfix）请在描述里附上本清单的勾选结果。合并 master 会发布稳定版，请使用 Create a merge commit。
